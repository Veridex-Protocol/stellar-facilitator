## Implementation Order

1. Catalog live-term admission and periodic revalidation, with isolated failure tests.
2. Honest Prometheus exporters and the canonical error contract.
3. Search baseline/report expansion and provider-policy boundary semantics.
4. MCP untrusted-data boundaries and a linked security matrix.
5. RPC ambiguity/failover design and implementation, then concurrency/failure/federation live harnesses.

The first four items are deterministic and can be validated locally. RPC and large testnet
harnesses have a wider settlement blast radius and must not be declared complete without
real network evidence.
