Safe to claim: fresh reproducible testnet exact/direct `upto`, prior custom HTTP `upto`, truthful `/supported`, settlement/receipt/Bazaar, keyless MCP, external SDK payment, durable outbox, local signer quarantine, 50-query search regression, measured three-signer saturation, Prometheus endpoints, canonical errors, and testnet loopback RPC failover.

Do not claim: production throughput, a diverse activity corpus, upstream stock Stellar `upto` interoperability, deployed smart-account/stablecoin enforcement, independent-provider or pubnet maturity, production readiness, independent security audit, mature public provider reputation, or multi-operator federation maturity.
